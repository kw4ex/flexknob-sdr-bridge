# FlexControl Knob for Thetis 1.0.0

**Windows only.** This program runs on Windows 10 and 11 only. The installer and helper files are Windows batch files and will not work on a Mac or Linux.

Use the **FlexRadio FlexControl USB tuning knob** with **Thetis, Thetis HL2 and SDR-VST3**, with **no amplifier needed**. A small stand-alone program for Windows 10/11 with its own installer. Turning tunes VFO A; presses switch to VFO B, AF volume, AGC gain, RIT, XIT, tuning step or TX drive; twelve presses are each programmable. A browser panel (and an optional window inside Thetis) shows what the knob does right now.

## How to download (no GitHub account needed)

1. Plug in the knob. In Thetis turn on the TCI server (127.0.0.1:50001), then close Thetis.
2. Look at the **Assets** list at the bottom of this page and click **FlexKnob_for_Thetis_v1.0.0.zip**. Your browser saves it, normally in your **Downloads** folder.
3. **Do not click "Source code (zip)" or "Source code (tar.gz)"**. Those are for programmers.
4. Right-click the file in Downloads, **Extract All…**, **Extract**.
5. Open the folder and double-click **1_RUN_THIS_Installer.bat**. Press Enter to accept the answer in [brackets].
6. Open http://127.0.0.1:8090 in your browser to see what the knob does and to choose what each press does.

The Assets list also has the illustrated **READ ME FIRST** guide (PDF). To go back to an older version later, open the [Releases page](https://github.com/kw4ex/flexknob-sdr-bridge/releases).

Only one program can use the knob at a time: close DDUtil, and switch off the knob in the KPA1500 Thetis/SDR Bridge if you have it (the installer helps).
